参数 / 总线
-----------
147 个参数
2 个输入总线（Main + Sidechain）
1 个输出总线（Stereo）
3 × 8 个 Bus 槽 + 8 个 Master 槽 + 固定 Morph

[PASS] 默认链路
       输入 RMS 0.106066
       输出 RMS 0.107295（约 +0.2 dB）
       默认 COMP makeup +12 dB，OUTPUT +4 dB
       默认 LFO Morph Depth = 0，不会自动晃动

[PASS] 三条 Bus
       Bus 1 / Bus 2 进入最终 Morph
       Bus 3 作为并行链由 BUS 3 旋钮混合
       每条 Bus 独立 8 个槽，Bus 1 默认 8 个效果
       Bus 2 / Bus 3 默认 8 个空槽
       默认 BUS 1 OUT 100%，BUS 2 OUT 0%，BUS 3 OUT 0%
       BUS 2 OUT 是直接并行发送；Morph B 取自 Bus 2 链，0% 时仍可被 Morph 融合
       槽位可在当前 Bus 内拖动换序

[PASS] 槽位参数独立
       32 个槽各有独立参数状态
       [PASS] duplicate compressor in the same bus keeps independent parameters
       [PASS] bus 2 compressor keeps independent parameters
       [PASS] master compressor keeps independent parameters
       [PASS] independent slot parameters survive state reload

[PASS] 拖拽插入 / 删除
       拖动时显示插入线、12px 空位和 DROP 标签
       [PASS] insert between modules shifts left
       [PASS] insert keeps target module
       [PASS] insert places dragged module after target
       删除后立即左移，不在原地留空
       [PASS] remove closes the gap immediately
       [PASS] remove leaves empty capacity at the end
       空位只保留在链尾

[PASS] Master
       Master 有独立 8 个槽
       处理顺序：Bus 1/2 Morph + Bus 3 → Master → OUTPUT
       Master 对所有 Bus 生效
       默认 Master 8 个空槽
       [PASS] master chain output is finite
       [PASS] master chain processes the summed buses

[PASS] Morph + LFO 合并
       LFO 不再占独立槽
       Morph 页包含 MORPH / B TRIM / CURVE / B WIDTH
       B SOURCE：SIDECHAIN / BUS 2 / INTERNAL
       LFO：RATE / DEPTH / PHASE / SHAPE
       默认 LFO DEPTH = 0

[PASS] Sync 模式切换
       ECHO：SYNC 后 TIME 旋钮变成 DIVISION（1/32…1 BAR）
       GRAIN：SYNC 后 DENSITY 旋钮变成 DIVISION
       不再有单独的 DIVISION 控件
       [PASS] echo division survives view changes
       [PASS] echo division does not jump to 1 BAR
       [PASS] echo division keeps its division label
       关闭 SYNC 恢复 TIME / DENSITY

[PASS] Filter
       24 dB 状态变量滤波器
       1000 Hz 低通：200 Hz 保留，8 kHz 明显衰减
       1000 Hz 高通：100 Hz 明显衰减
       曲线只读，不响应拖动

[PASS] EQ
       3 段 shelf/peak EQ
       Low +12 dB 提升低频
       修复右声道每个音频块被 reset 的 bug（之前杂音来源）
       左右声道独立保持滤波器状态，并清理 denormal
       曲线只读，不响应拖动

[PASS] Chorus / Flanger
       重写为线性插值延迟 + 12.5 kHz 湿声低通 + 反馈软限幅
       修复反馈平滑被同一样本读取两次的问题
       [PASS] chorus output is finite
       [PASS] chorus produces wet signal
       Chorus / Flanger 输出有限、有音频
       Chorus 可视化已移除

[PASS] Grain / Autochroma
       Buffer / Offset / Rate / Size / Density / Pitch / Spray /
       Feedback / Mix / Width
       Snap：OFF / 1/16 / 1/8 / 1/4

       粒子缓冲与输出有限

已知边界
--------
- 同时只支持一个插件实例内的固定模块类型；不同 Bus/Master 可各放一个。
- Custom DLL 在插件构造时扫描；替换 DLL 后需重开插件。
- 仅支持 x64 Windows VST3。
- 48000 样本单块未作为测试项；使用标准 512 块验证。
